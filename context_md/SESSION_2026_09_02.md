### Bugs Fixed

#### 1. `encodeURIComponent` broke OpenAlex & Crossref URLs
**Files:** `src/lib/openalex.ts`, `src/lib/crossref.ts`

The code was encoding DOIs in the URL path (`10.1038/nature12373` → `10.1038%2Fnature12373`), which broke both APIs. Removed `encodeURIComponent` from URL path construction.

#### 2. OpenAlex batch filter syntax was wrong
**File:** `src/lib/openalex.ts`

The code used `openalex:W1|openalex:W2|openalex:W3` (repeated keys) but OpenAlex requires `ids.openalex:W1|W2|W3` (single key, pipe-separated values). Same bug existed for DOI filter (`doi:10.1/a|doi:10.1/b` → `doi:10.1/a|10.1/b`).

#### 3. DOI validation regex was too strict
**File:** `src/app/api/analyze/route.ts`

Regex `/^\d{4,9}\/.+/` required 4-9 digits before the slash, but DOIs start with `10.` (only 2 digits). Fixed to `/^10\.\d{4,9}\/.+/`.

#### 4. No DOI cleanup for user input
**Files:** `src/lib/openalex.ts`, `src/app/api/analyze/route.ts`, `src/app/api/papers/[doi]/route.ts`

Users could paste full URLs (`http://localhost:3000/api/papers/10.1038/...`) as DOIs. Added `cleanDOI()` function that strips `https://doi.org/`, localhost URLs, and other prefixes.

#### 5. Gemini rate limiting (429 errors)
**File:** `src/lib/gemini.ts`

34 sequential Gemini calls hit the 10 RPM free tier limit. Added:
- Rate limiter with 6.5s minimum between requests
- 60s wait on 429 (reads `Retry-After` header)
- Max 3 retries to prevent infinite loops
- Counter reset when rate limit window expires
